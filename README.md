# tg-engine: движок сети Telegram-каналов

Один движок, каждый канал задаётся отдельным YAML-файлом в `channels/`. Цикл работы:

1. **Сбор** (раз в 30 мин): RSS-ленты и Reddit. Дубли отсекаются по ссылке (без utm-меток) и по похожему заголовку, старьё и стоп-слова отфильтровываются.
2. **Переписывание**: Claude решает, подходит ли материал нише, и пишет оригинальный пост в голосе канала. Только факты из источника, без копипаста. Текст источника передаётся как данные, а не инструкции (защита от prompt injection).
3. **Модерация** (режим `review`): черновик приходит в твой приватный чат с кнопками ✅/❌. Когда качество устроит, переключаешь канал на `mode: auto`.
4. **Публикация**: равномерно по активным часам со случайным разбросом ±30%, дневной лимит, без ночных постов. Новости старше 12 часов в очереди не публикуются.
5. **Взаимный пиар**: раз в N дней канал рекомендует соседа по сети (не раньше, чем выйдет 5 обычных постов).

## Защита сети

- У каждого канала свой бот и свой токен. `check` предупредит, если два канала сидят на одном боте.
- Если бота выкинули или токен отозван, канал сам встаёт на паузу и шлёт алерт, остальные работают дальше. Снять паузу: `python -m engine resume <id>`.
- Обработка flood-wait (429) от Telegram.
- Дневной предохранитель на число вызовов LLM (`max_llm_calls_per_day`).
- Санитайзер HTML: в Telegram уходят только разрешённые теги.

## Запуск

```bash
cp .env.example .env        # вписать ключ Claude API и токены ботов
pip install -r requirements.txt
python -m engine check                    # токены валидны, боты админы каналов
python -m engine preview crypto_news -n 3 # собрать и показать 3 поста, ничего не публикуя
python -m engine preview crypto_news --fake  # то же без вызова LLM
python -m engine run                      # рабочий цикл
python -m engine stats
```

На сервере: `docker compose up -d --build`. База в `./data`, конфиги каналов подключены томом, новый канал = новый YAML + перезапуск.

## Новый канал

Скопируй любой файл из `channels/`, поменяй `id`, `title`, `niche`, источники, стиль, расписание и имена переменных с токеном. Создай бота в @BotFather, добавь его админом канала с правом публикации, впиши токен в `.env`.

## Модель

По умолчанию `claude-opus-5-5` с `effort: low`. Для экономии можно поставить `claude-haiku-5-5` в `settings.yaml`, но сначала сравни качество через `preview`. Включены серверные фолбэки (`fallbacks: "default"`): если модель откажет на запрос, его подхватит другая.

## Тесты

```bash
pip install pytest && python -m pytest -q
```

## Ограничения

- Reddit часто блокирует анонимные запросы с IP серверов. Если так случится, нужен OAuth-доступ к Reddit API или замена источника.
- Картинки из источников берутся только там, где включено `use_images` (по умолчанию только NASA, это общественное достояние). Чужие фото без прав лучше не постить.
